How this works — each file's own byte structure is read directly and the metadata segments (EXIF, GPS, timestamps, author/software tags, Photoshop caption data) are cut out at the byte level. Compressed image data is never decoded or re-encoded, so pixel quality is unchanged — this is removal, not recompression. Color profiles are left in place on purpose, since they affect how colors render rather than who took the photo. HEIC is handled a little differently: rather than cutting the metadata item out of the container, its contents are overwritten with zeros in place, which is safer against corrupting the file — if a HEIC's structure can't be confidently read, the original is left untouched and flagged rather than risked.

Verified, not just promised — after cleaning, each file is re-scanned with the same detector used to find the original metadata, so you see an actual "0 fields remain" result rather than a claim. This page also overrides fetch and XMLHttpRequest on load, so any network call — intentional or not — is blocked and counted live in the badge above.
