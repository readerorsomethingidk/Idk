Photos carry a quiet record of where they came from — camera model, timestamp, sometimes exact GPS coordinates. Clearfile finds that record and removes it, entirely inside this browser tab.

Your image is never uploaded — there is no server in this tool

How this works — the image is redrawn onto an in-memory canvas and re-encoded from scratch. Camera/EXIF tags, GPS data, embedded color profiles, and text chunks don't survive that re-encode, so the file that downloads is a clean copy with none of the original's hidden fields. Nothing is transmitted anywhere at any point — check your browser's network tab if you'd like to see for yourself.
